# 🚨 ERRO: ERR_CONNECTION_REFUSED (-102)

## Diagnóstico
O navegador não consegue conectar em `http://localhost:5173/` porque o **Frontend (Vite) não está rodando**.

---

## ✅ Solução Rápida (3 passos)

### Passo 1: Abra Terminal na Pasta Frontend
```bash
cd c:\xampp\htdocs\cotton\frontend
```

### Passo 2: Instale Dependências
```bash
npm install
```

Aguarde até ver:
```
added XXX packages
```

### Passo 3: Inicie o Vite
```bash
npm run dev
```

**Aguarde aparecer:**
```
VITE v5.0.11  ready in XXXms

  ➜  Local:   http://localhost:5173/
  ➜  press h + enter to show help
```

### Passo 4: Abra no Browser
```
http://localhost:5173/
```

---

## ❌ Se Ainda Não Funcionar

### Problema: "Port 5173 already in use"

```bash
# Mate o processo
taskkill /IM node.exe /F

# Aguarde 5 segundos
timeout /t 5

# Tente novamente
npm run dev
```

### Problema: "Cannot find module"

```bash
# Limpe e reinstale tudo
cd c:\xampp\htdocs\cotton\frontend
rm -r node_modules package-lock.json
npm install
npm run dev
```

### Problema: Vite não inicia com erro

```bash
# Verifique versões
npm list vite
npm list react

# Se tiver erro, reinstale tudo
npm install --force
npm run dev
```
